# LifeBridge

**LifeBridge** is a healthcare website where users can view medical services, doctor profiles, patient testimonials, and appointment information. The website is designed with a clean layout and simple navigation to make the information easy to find and understand.

## Features

* Home Page
* Medical Services
* Doctor Profiles
* Patient Testimonials
* Appointment Section
* Contact Information
* Responsive Design
* Modern UI/UX

## Technologies

| Technology       | Purpose                                 |
| ---------------- | --------------------------------------- |
| **React**        | Building the website and user interface |
| **JavaScript**   | Website functionality and interactions  |
| **Tailwind CSS** | Styling and responsive layouts          |

## Project Purpose

LifeBridge was created to provide a simple way for users to:

* Browse medical services
* View doctor information
* Read patient testimonials
* Check appointment information
* Find contact details

## Design

The website uses a clean and modern design with a focus on:

* Easy navigation
* Clear information
* Consistent layouts
* Responsive pages
* Simple user interactions

## Project Status

**⏸️ On Hold**

LifeBridge is currently on hold. The project was previously developed using React, JavaScript, and Tailwind CSS, and the existing development will be continued when the project is resumed.
