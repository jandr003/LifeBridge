**LifeBridge** is a healthcare website that helps visitors explore medical services, meet the care team, read patient testimonials, find answers to common questions, and access appointment and contact information.

## Live Demo

[View LifeBridge Live](https://life-bridge-phi.vercel.app)

## Features

* Responsive healthcare landing page
* Hero and about sections
* Medical services
* Healthcare team profiles
* Blog section
* Patient testimonials
* Frequently asked questions
* Appointment booking modal with form validation
* Contact information and social links
* Responsive navigation and mobile-friendly layouts

## Project Purpose

LifeBridge was developed to make essential healthcare information easier to explore. Visitors can learn about available services and the care team, read testimonials, find answers to common questions, and submit appointment requests.

## Design

The website uses a clean visual hierarchy, consistent typography, and organized content sections. Dedicated layouts for services, team profiles, articles, testimonials, and contact information help visitors navigate the website and find relevant information.

## Responsive Design

LifeBridge is designed to adapt to desktop and mobile screen sizes. Its navigation, content sections, images, and layouts adjust to the available screen space.

## Development

The frontend uses React and JavaScript, with Vite handling the development server and production build. Tailwind CSS provides the styling, while Lucide React supplies the interface icons. The appointment booking modal includes client-side form validation.

## Project Status

**Completed & Deployed**

LifeBridge is a completed website project and is currently available online through the live demo.
