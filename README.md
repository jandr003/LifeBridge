# LifeBridge

**LifeBridge** is a healthcare website that provides information about medical services, doctors, and patient care. Users can browse different services, check doctor profiles, read patient testimonials, and schedule appointments through the website.

## ✨ Features

The project includes the following features:

* **Home Page**
* **Medical Services**
* **Doctor Profiles**
* **Patient Testimonials**
* **Appointment Section**
* **Contact Information**
* **Responsive Design**
* **Modern UI/UX**

## 🛠️ Technologies

| Technology       | Purpose                        |
| ---------------- | ------------------------------ |
| **React**        | Frontend development           |
| **JavaScript**   | Functionality and interactions |
| **Tailwind CSS** | Styling and responsive design  |

## 📋 Requirements

Before running the project, make sure you have:

* **Node.js 18 or later**
* **npm**
* **Modern Web Browser**
* **Visual Studio Code** or another code editor

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/jandr003/LifeBridge.git
```

### 2. Navigate to the Project Directory

```bash
cd LifeBridge
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The project will run on the local development address provided by Vite.
