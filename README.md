# LifeBridge

LifeBridge is a healthcare website that provides information about medical services, doctors, and patient care. Users can browse healthcare information and schedule appointments through the website.

## Features

- Home Page
- Medical Services
- Doctor Profiles
- Patient Testimonials
- Appointment Section
- Contact Information

## Tech Stack

- React
- JavaScript
- Tailwind CSS

## Requirements

- Node.js 18 or later
- npm

## Platform

- Desktop
